# L4 Road-Contact Causality Report

**Build:** `0.3.0-alpha.291`

**Evidence viewport:** 1600×900

## Result

PASS. All seven existing major threat families now expose the same readable, presentation-only causal sequence without changing authoritative combat state.

## Implemented grammar

- Forecast names the threat and exact steps to contact.
- Approach names the threat's authored route into the fortress.
- Target Lock repeats the authoritative module target.
- Wind-up gives each family a stable attack signature.
- Response Window names a concise counter while the dossier retains the complete authored counter.
- Impact repeats the authoritative damage report.
- Consequence condenses the resulting dependency change.
- Settle holds the cleared road before arrival.

The active dossier keeps intent, target reason, response, predicted durability change, and dependency cascade visible together. The replay lasts roughly 2.4 seconds at normal motion so the phases can be read; Reduced Motion jumps directly to the already-resolved consequence. No animation callback changes targeting, damage, random streams, resources, saves, or encounter progress.

## Threat coverage

The deterministic phase contract covers Road Raider, Climber, Burrower, Storm Front, Siege Beast, Flood Surge, and Civic Guardian. Tests assert each family's forecast distance, approach route, preferred targets, counter, signature, response cue, authoritative impact text, dependency consequence, and shared settle state.

# Playtest Build Identity

## Player problem

The title described the artifact as `ALPHA` immediately before a version that already contained `alpha`, while Pause showed the bare version with no context. Both were technically accurate but looked unfinished and made screenshots less consistent when testers reported an issue.

## Copy contract

- The shared identity is **Playtest Build · v&lt;exact application version&gt;**.
- The title prefixes that identity with **Two Playable Regions** to preserve scope.
- Pause uses the same labelled identity without repeating the title scope.
- Build & Local Data, saves, feedback exports, and compatibility checks continue to use the authoritative raw application version.
- No label invents a release-candidate or commercial-readiness claim.

## Scope

This changes presentation only. It does not alter version validation, save compatibility, export metadata, update behavior, or release readiness.

# Screen review grid

Use the rows relevant to the captured state. Record direct visual evidence before suggesting a cause.

| Dimension | Pass condition | Common failure |
|---|---|---|
| Phase | Current phase and location are visible once | Competing headings describe different phases |
| Primary action | One action has dominant placement and treatment | Several controls demand equal attention |
| State | Required values are readable without crossing the screen repeatedly | State is duplicated, clipped, or detached from the decision |
| Preview versus receipt | Forecast, selected, committed, and applied states are visibly distinct | A preview looks spent or an applied cost looks optional |
| Center stage | Fortress, map, threat, or event is the obvious subject | Dense labels turn the center into another text panel |
| Right dock | One selected subject, consequence, or service is explained | Several unrelated decisions share the dock |
| Continuity | The same fortress and damage persist across adjacent phases | A generic illustration replaces the affected machine |
| Place identity | Region and location read through physical motifs | Only the title distinguishes places |
| Threat identity | Approach lane, silhouette, target, and counter agree | Decoration contradicts or obscures targeting |
| Geometry | Labels, paths, icons, and focus rings do not collide | Connector lines cross text or badges cover controls |
| Accessibility | Text and symbols preserve meaning without color or motion | State depends on hue, hover, animation, or tiny copy |

## Evidence set

At minimum, inspect title, first actionable state, map browse, selected route, travel, contact before impact, impact/consequence, authored event, arrival, recovery, and Debrief. Prefer adjacent frames from one clean-save run.

For 1280×720 at 110% text, check all required actions are visible, button labels remain distinct, and no critical explanatory text is pushed below the fold. For high contrast, check semantic colors retain labels or symbols. For reduced motion, check phase and threat changes remain visible in static composition.

## Fix discipline

Prefer removing duplication, strengthening grouping, moving labels off connector paths, or reusing authoritative presentation data. Do not shrink critical text to solve density. Do not change simulation timing or values to make a frame cleaner.

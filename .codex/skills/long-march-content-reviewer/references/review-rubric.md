# Content review rubric

Score is diagnostic, not an approval substitute. Any Blocker fails the review regardless of total.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Mechanical truth | Contradicts or invents state | Broadly right, imprecise | Traced to exact command/state behavior |
| Cost disclosure | Hidden or post-commit | Present but vague | Exact and visible before commitment |
| Choice quality | Cosmetic or obvious | Different but lopsided | Competing legitimate priorities |
| Causal receipt | No visible result | Immediate result only | Immediate result plus implemented callback |
| Continuity | Conflicts with IDs/history | Compatible but generic | Uses relevant people/place/memory precisely |
| Regional identity | Interchangeable | One local noun | Physical and operational identity reinforce each other |
| Character voice | Same narrator in costume | Role is visible | Belief, expertise, and pressure shape the line |
| UI fit | Likely clipped or repeated | Readable with friction | Scannable in real surface and input modes |
| Accessibility | Meaning relies on presentation | Some redundant cues | Text, state, focus, and alternatives agree |
| Prose quality | Stock or inflated | Serviceable | Concrete, economical, varied, and human |

A release-ready authored unit normally scores 2 for mechanical truth, cost disclosure, and causal receipt. A lower score there requires a concrete implementation or copy correction, not stylistic preference.

## Evidence questions

- Which method or command applies this effect?
- Does the UI show the same number before and after commitment?
- Is the choice still meaningful with names and flavor removed?
- Can failure continue through a viable, visible route?
- Does save/load preserve the active choice and its later memory?
- Does the Debrief attribute cause rather than merely list damage?
- At 110% text and 1280×720, what happens to the longest localized string?
- Can keyboard, pointer, and controller users reach and understand the same action?

## Anti-slop edit test

For every paragraph, underline concrete nouns, player-relevant verbs, and verifiable claims. If mostly abstract adjectives and theme language remain, request a rewrite. Search repeated copy for the same cadence, metaphor, and moral framing; varied names do not make duplicated writing distinct.

Do not flatten authored texture into telemetry. Exact mechanics and human voice should coexist, usually in separate structured fields or successive sentences.
